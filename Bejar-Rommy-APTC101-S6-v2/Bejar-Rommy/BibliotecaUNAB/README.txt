BIBLIOTECA UNAB - SEDE ANTONIO VARAS (APTC101, Semana 6, Sumativa 2)

Abrir en NetBeans: File > Open Project > carpeta BibliotecaUNAB. Luego Clean and Build y Run.
Clase principal: cl.biblioteca.Main (corre una demostracion por consola y abre la ventana).
Pruebas automaticas: clase cl.biblioteca.prueba.PruebaLogica (Run File).
Los datos se guardan en la carpeta "datos" (usuarios.txt, libros.txt y prestamos.txt), que se crea sola.
